# AI4Math 周报（2026 年 11 月 14 日—11 月 20 日）

## 一、AI4Math 生态雷达

[项目地址（Gitee）](https://gitee.com/testimoa/ai4math-radar)，分支为 `main`；线上站点为
<https://irrelaceable.github.io/ai4math-radar/>。

AI4Math 是一个面向 AI for Mathematics 的公开资讯站：把论文、模型、研究机构等公开消息整理成 700 多条可回到原文核查的事件，读者可以从最新动态、时间线、研究图谱和专题入口浏览。

本周的重点是让网站更好用、更好读，按模块来看：

- 研究图谱模块，把研究内容按规则划入细分领域后做图形化显示，领域分布一眼看清；
- 事件详情与持续追踪模块，能顺着脉络看到一条事件的后续进展和核验；
- 浏览入口模块，导航和版式统一，五个入口各管一块，找内容更快；
- 全站分类规则定稿并逐条核对，筛选和统计更可信；
- 采集流程从四次模型调用合并为一次，为后续扩量做准备。

改动已提交 `8a9e89d`，并同步至 GitHub 与 Gitee。

| 模块 | 负责人 | 做了什么 |
| --- | --- | --- |
| 研究图谱 | 雷（IRrelaceable） | 研究图谱模块，新增研究内容聚类图形化显示。通过设置划分规则，把研究内容归入数学领域与研究主题等细分领域，再用聚类散点图和交叉矩阵展示，点选图形即可回到对应记录；图和表由原来的两页合并到一页。 |
| 事件详情与持续追踪 | 雷（IRrelaceable） | 事件详情与持续追踪模块，新增事件脉络与后续进展展示。通过建立跨来源检索与关系判定规则，把后续、核验、更正等关联内容归到同一条事件线下；目前只在离线回放里核对，还没有接入自动入库。 |
| 浏览入口（最新进展、时间线等） | 雷（IRrelaceable） | 浏览入口模块，统一了导航和页面版式，五个入口各管一块。精简事件卡片信息、把数学分类下移到卡片底部、去掉页脚重复文案。 |
| 数学档案 | 雷（IRrelaceable） | 数学档案模块，修正了两处显示问题。来源链接改为按基线对齐，让页面名和网址排在同一水平线上；封面大数字调整行高并留出间距，不再压住下方的说明文字。 |
| 全站分类规则 | 雷（IRrelaceable） | 分类规则定稿并逐条核对。删去研究子类型、研究方法、核验状态三个维度，写明证据等级、来源类型、AI 参与程度、发表状态的判定规则，并把九个维度的存量标签全部重筛修正，让筛选和统计更可信。 |
| 采集与部署 | 雷（IRrelaceable） | 采集流程从四次模型调用合并为一次，补齐缺字段判失败、输出格式与 token 记录，实际效果待实测；同时停掉定时抓取、保留手动触发，提交后 GitHub Pages 构建成功、Gitee 已同步，类型检查、lint 与 326 项测试通过。 |

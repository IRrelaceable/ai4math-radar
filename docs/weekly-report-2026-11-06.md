### 功能更新

- **雷｜站点形态。** 改为纯静态导出，数据在构建时生成，移除服务端 API；中文在 `/`、英文在 `/en/` 分别构建，本地一条命令同时启动两站。定时采集回写 `data/ingested`，GitHub Actions 完成双语言构建与发布。
- **雷｜信息架构。** 统一首页、事件流、详情与来源页版式；事件脉络只保留在详情页，导航收敛为最新、时间线、方向、来源、关于。
- **雷｜事件详情与脉络。** 详情页新增“关键事实”“证据与状态一览”“同类事件”与“方向前后事件”；事件脉络按人物、机构、项目、模型与基准生成共现时间线，标出起点、最新与当前事件。
- **雷｜时间线与事件流。** 时间线按年 / 十年分组，月份可折叠，支持深链定位与全年展开；事件流新增卡片 / 紧凑视图，筛选保留分类、方向、时间、证据与来源。
- **雷｜数据与评级。** 事件扩充至约 **650 条**，最早可追溯到 **1956 年**；从 arXiv 与 NeurIPS、ICML、ACL 等会议论文集回补历史事件。E3 统一为“单方声明”，证据等级只列出数据中实际存在的档位。
- **雷｜文档。** 重写中英文 README，补充徽章、页面截图、功能路由表、数据与信任模型与 Roadmap；新增首页、时间线、事件详情三张截图及周报记录文件。

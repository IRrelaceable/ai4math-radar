| 任务 | 负责人 | 结果 |
| --- | --- | --- |
| 整理时间线与题目分类 | 成 | 核对 **52 条事件、62 条题目及事件映射记录**，保留题目、领域、模型、参与人及人机分工；区分原问题、改编题、缺题面和非解题事件，明确其中 **45 道可独立测试**。 |
| 整理各问题的资源投入 | 成 | 复核各事件的算力、token、耗时、费用和人员字段；区分单题与整批投入、模型运行与人工核验，未公开的数据明确标注。 |
| 核对关键数据与原始来源 | 成 | 整理 **73 项资源来源索引**，抽查论文、官方报告和项目记录。对“两个高斯混沌之和”单独说明：原研究有人类数学家辅助，单题算力、token、费用和精确耗时未披露。 |
| 整理 First Proof 逐题对照 | 成 | 汇总两批实验、多个系统的 **90 条资源记录**，保留逐题 token、费用及统计范围；原报告总数与逐题合计不一致的地方注明差异。 |
| 修正正文与台账不一致 | 成 | 修正 GPT-f 模型规模描述，将论文集合数量注明为对应日期的历史快照，同步更新 CSV 和 JSON，避免正文与数据表各说一套。 |
| 完成交付与版式检查 | 成 | 交付 **71 页主报告**、2 份 CSV 台账、2 份 JSON 数据及交付摘要；检查全部页面，修正文末大面积留白，并核对记录数量和文件间一致性。 |

## 三、数学问题复现与长上下文测试

针对“两个高斯混沌之和的定量四阶矩界”，在复盘原 GLM 卡点的基础上，补做了 1M 上下文模型测试，并排查 256K 上下文模型的可用接口。

| 任务 | 负责人 | 结果 |
| --- | --- | --- |
| 复盘原 GLM 长期卡住的记录 | 成 | 区分数学推导、摘要归档和接口失败，整理反复压缩、遗漏已有路线、纠错状态混淆等证据；确认原 GLM 运行虽有“完成”标签，但最终输出不是证明，不能计为解题成功。 |
| 测试 1M 上下文模型 | 成 | 使用阿里云 **DeepSeek V4 Pro（1M 上下文）**完成同一题测试，已跑通并产出解答，**通过 GPT 核验**。 |
| 排查 256K 上下文模型接口 | 成 | 查找阿里云、硅基流动等平台的可用模型，暂未找到符合本次测试要求的 **256K 上下文接口**，该档位对照测试尚未开展。 |
| 整理 128K 上下文压缩学习报告 | 成 | 完成 **13 页报告、8 个学习单元**，覆盖上下文分配、关键公式保留、历史推导回读、重复识别和对照实验设计。 |
| 制定状态卡与压缩验收模板 | 成 | 明确记录原题条件、已提出的结论、来源、纠错和待证步骤；分别检查“信息是否保留、续解是否推进、证明是否正确”，配套模板已交付。 |
| 核对原 GLM 队列状态 | 成 | 此前检查时，原 GLM 定时续跑已暂停，未发现该队列后台解题进程；128K 压缩方案尚未经过实跑验证。 |
